# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub: [Report a vulnerability](https://github.com/javimentallab/claudepassredactor/security/advisories/new).

Say what you found, how to reproduce it and which version you used. English or Spanish are both fine.

This project has a single maintainer, so replies are best effort. I aim to answer within 14 days.

## What counts

Secrets that are left in clear, secrets that end up in a log or a fingerprint file, and anything that makes the hook write outside the memory folder.

## Supported versions

Only the latest release gets security fixes.
